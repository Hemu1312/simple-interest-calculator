# Simple Interest Calculator

## Project Description

The Simple Interest Calculator is a project that calculates the simple interest based on the principal amount, rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Input Fields

- Principal Amount (P)
- Rate of Interest (R)
- Time Period (T)

## Example Calculation

Principal Amount = 1000  
Rate of Interest = 5%  
Time Period = 2 years  

Simple Interest = (1000 × 5 × 2) / 100

Simple Interest = 100

## Features

- Easy calculation of simple interest
- Takes user input values
- Provides accurate interest calculation
