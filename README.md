# Simple Interest Calculator

A simple Bash-based calculator that computes simple interest based on user-provided principal amount, annual rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Inputs

* **Principal:** The initial amount of money.
* **Rate:** The annual rate of interest in percentage.
* **Time:** The time period in years.

## Usage

Run the `simple-interest.sh` script and enter the requested values.

## Example

If the principal is 1000, the rate is 5%, and the time is 2 years:

Simple Interest = (1000 × 5 × 2) / 100 = 100
